# Unit tests that are left out of every unit-test run: the two commit checks
# (.claude/hooks/pre-commit-tests.sh, .git/hooks/pre-commit),
# scripts/merge-check.sh, scripts/build.sh, and any run a Claude session makes
# itself. The unit-test counterpart of scripts/vmtest/known-flaky.txt.
#
# One fully-qualified test identifier per line, in the form xcodebuild's
# -skip-testing takes: Target/Class/method for XCTest, Target/Suite/function()
# for Swift Testing. Blank lines and lines starting with # are ignored.
# scripts/unit-quarantine-args.sh turns this file into the -skip-testing
# arguments.
#
# A listed test is not run at all, so it cannot report a new way of breaking.
# Rules for an entry:
#   - Above it, a comment block: the date, what fails and why (a diagnosis,
#     not "it was already failing"), and the task-board id of the fix.
#   - A test that fails only because something outside the app is missing
#     (Zotero not running, Pandoc not installed) does not belong here — make
#     it skip itself with XCTSkip, as ZoteroServiceConnectionTests does.
#   - The entry is removed by the change that fixes the test, after that
#     change has shown the test passing.
